## 🚀 How to Run on Live Server (Whenever You Want in Future)

Aap jab bhi apna portfolio run karna chahein, terminal mein bas ye 2 lines chalaayein:

```bash
cd ~/Desktop/abhay-futuristic-portfolio
python3 -m http.server 8000
```

Phir apne kisi bhi browser mein open karein:
👉 **[http://localhost:8000](http://localhost:8000)**

### 🛑 How to Stop / Kill the Live Server
- **Method 1:** Jis terminal window mein server chal raha hai, wahan keyboard se **`Ctrl + C`** press karein.
- **Method 2:** Agar server background mein chal raha ho ya port busy ho, toh terminal mein ye command run karein:
  ```bash
  lsof -ti :8000 | xargs kill -9
  ```
